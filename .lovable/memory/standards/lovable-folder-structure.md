## Summary

The canonical structure of `.lovable/` is defined in `spec/17-consolidated-guidelines/21-lovable-folder-structure.md`. Memory folder is **singular** (`memory/`, never `memories/`).

## Details

Required root files: `overview.md`, `strictly-avoid.md`, `user-preferences`, `plan.md`, `suggestions.md`. Required folders: `memory/` (with `index.md`), `prompts/`, `cicd-issues/`. Single-file convention — never create per-task subfolders.

AI reading order: overview → strictly-avoid → user-preferences → memory/index → plan → suggestions.
